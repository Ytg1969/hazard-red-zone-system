# Five-Minute Multi-Hazard Demo Guide

## 0:00–0:35 — Operational Overview
Select **All Demo Cities** + **Combined Multi-Hazard**. Explain that Puri, Guwahati and Chennai are real geography anchors chosen to demonstrate different hazard contexts; operational values and hazard footprints are clearly labelled DEMO.

## 0:35–1:20 — Red Zone Map
Switch between Puri, Guwahati and Chennai. Point out risk classes, synthetic hazard footprints and experimental coordination zones. State that coordination zones help EOC briefing but do not change the risk score or evacuation decision.

## 1:20–2:15 — Risk Analysis
Choose a named hazard profile. Show the transparent hazard-indicator breakdown, data completeness, then the frozen final risk contribution chart. Emphasize that prototype hazard weights are visible and replaceable, not hidden or presented as official standards.

## 2:15–3:30 — Relocation Planner
Select a high-risk habitation. Show unsafe/full shelter filtering, suitability ranking, multi-shelter split and remaining deficit. Show the system-wide capacity-safe plan; explain that capacity cannot be double-booked and multi-city assignments remain local.

## 3:30–4:05 — Scenario Studio
Change the policy emphasis. Show locations changing class and affected population while the hazard profile stays fixed.

## 4:05–4:35 — External Context
Show NDMA SACHET-compatible CAP/RSS infrastructure. If a verified live feed is unavailable, show the DEMO/CACHED state instead of pretending it is live. Optional USGS earthquake context is a separate external feed and does not silently alter risk.

## 4:35–5:00 — Export and close
Download the PDF action plan. Close with: the platform converts hazard context into explainable red-zone priorities and capacity-aware relocation options, while keeping officials in control.

## Short 3-minute fallback
Overview → Red Zone Map → Risk Analysis → Relocation Planner → PDF export.

## Failure handling
- Internet unavailable: continue fully offline with DEMO data.
- SACHET/USGS unavailable: show fallback state; core analysis continues.
- Road graph unavailable: continue with labelled haversine fallback.
- Map tiles unavailable: use tables/charts; analytical pipeline is local.
