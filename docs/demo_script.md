# SIH Demo Script

1. Open Overview and state the current data mode.
2. Show active/selected hazard context and summary KPIs.
3. Open Red Zone Map and select one high-risk habitation.
4. Open Risk Analysis and explain the main risk drivers in plain language.
5. Open Scenario Studio and change one weight; show the impact on classifications.
6. Open Relocation Planner; filter unsafe shelters, inspect effective capacity, route and recommendation.
7. Show any remaining capacity deficit and phased relocation priority.
8. Generate a Draft Disaster Response Action Plan.
9. Close with limitations, offline fallback and scalable live-data architecture.
